Glowvera is a modern, premium organic skincare website built with Next.js, TypeScript, and Tailwind CSS.
It showcases a clean luxury UI, product detail pages, blog integration, and responsive design optimized for performance and scalability.

✨ Features

🌸 Elegant, premium skincare UI

🛍️ Dynamic product listing & detail pages

📝 Blog section with rich content

📸 Before & After results section

📱 Fully responsive design

⚡ Optimized performance

🔒 Clean project structure

🛠 Tech Stack

Framework: Next.js

Language: TypeScript

Styling: Tailwind CSS

Deployment Ready: Vercel

📂 Project Structure
app/        → Application pages & components
public/     → Static assets (images, icons)
specs/      → Project specifications
history/    → Development history
🚀 Getting Started

Clone the repository and install dependencies:

npm install
npm run dev

Open:

http://localhost:3000
🌍 Deployment

This project is optimized for deployment on Vercel or any platform supporting Next.js applications.
