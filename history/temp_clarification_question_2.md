## Question 2: Content Management for Products/Routines

**Context**: The Key Entities describe product and routine data, but the spec doesn't specify how this content will be managed (e.g., static content in files, a simple admin interface, or a full CMS). This impacts the complexity of the backend and the flexibility for content updates.

**What we need to know**: How will product and skincare routine content be managed and updated?

**Recommended:** Option A - Content is static and updated directly by developers (e.g., editing JSON/Markdown files). This approach simplifies development for an initial showcase website, allowing for easier upgrades later if dynamic content management becomes a priority.

| Option | Description |
|--------|-------------|
| A      | Content is static and updated directly by developers (e.g., editing JSON/Markdown files). |
| B      | A simple, password-protected web interface for content updates will be provided. |
| C      | Integrate with an existing Content Management System (CMS) like Strapi, Contentful, or similar. |
